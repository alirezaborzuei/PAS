# PAS — Personal Portfolio Application

A personal portfolio project built to demonstrate modern frontend development, responsive UI design, reusable components, and a production-oriented Next.js setup.

## Highlights

- Modern Next.js application
- Responsive interface
- Tailwind CSS styling
- Reusable React components
- Clean project structure
- Docker-ready setup

## Tech Stack

- Next.js / React
- JavaScript
- Tailwind CSS
- Docker

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Purpose

This repository is a **personal portfolio/sample project** created to demonstrate practical frontend engineering skills. It does not contain company source code or confidential business data.
